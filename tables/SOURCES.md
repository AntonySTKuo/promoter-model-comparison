# Data sources

None of the data in `tables/` were generated by this study. Every file holds
measurements published elsewhere, re-extracted and reformatted into a common
layout. Credit for each dataset belongs to the study that published it.

Dataset IDs (DS01–DS30) follow Table 1 of the manuscript. `dataset_summary.csv`
maps each ID to its TF, regulation type, and file path, and is what the code
reads.

## File format

Column names differ between sources, so `common/loader.py` normalizes them.
After loading, every dataset exposes the same two columns:

- `ConExp` — basal promoter strength, *E*<sub>TF−</sub>
- `RegExp` — regulated promoter strength, *E*<sub>TF+</sub>

Both are on a linear scale. Units are arbitrary and differ between datasets,
which is why each dataset is fitted independently.
